# Ferramenta feita de scripts em Python rodados pelo Claude Code

A produção dos Vídeos (baixar Trechos, montar, legendar, exportar e agendar Posts) é feita por scripts em Python que o Claude Code executa no PC de casa, sem um app próprio com interface. O Claude Code já faz o papel de interface: ele escreve os Roteiros, escolhe as Cenas e roda os scripts, então um app com telas custaria muito mais para construir e manter sem ganho real para um canal de uma pessoa só.

## Considered Options

- **App com interface (desktop ou web)**: rejeitado pelo custo de construção e manutenção.
